# 全是噪声特征时的选择 AUC

两个 batch 的 X 来自同一套正态，尺度是相关系数 0.5 的 AR(1)。列与列之间有相关，边际是普通正态。Y 由两个没有写进 X 的正态潜变量经正弦、平方型和 tanh 生成。第二个 batch 里这两个潜变量的位置和尺度变了，所以 Y 的边际在变，但没有任何一列 X 进入结果，也没有任何一列 X 的分布在两个 batch 之间不同。

每次重复随机抽 4 个坐标当作假的支撑，这个支撑不看数据。选择 AUC 是变量重要度对这个 0/1 标签的 ROC。瞎猜是 0.5。每个格子是 30 次重复的均值，方括号里是这个均值的 2000 次百分位 bootstrap 95% 区间。每个 batch 的样本量是 280。

PermuCATE 的结果模型、伪结果模型和每个坐标的条件模型 `X_j | X_{-j}` 都是随机森林，倾向得分是随机森林分类器。LOCO R-risk 的结果模型也是随机森林，tau 仍是加权 ridge。GRF 用 econml 的 CausalForestDML，结果模型是随机森林，倾向得分是逻辑回归。

森林设定：PermuCATE / R-risk / domain 用 60 棵树、深度 5；PermuCATE 每个坐标置换 16 次；R-risk 做 4 折交叉拟合；Delta-SHAP 用 60 棵树的 TreeSHAP；GRF 用 40 棵树。
