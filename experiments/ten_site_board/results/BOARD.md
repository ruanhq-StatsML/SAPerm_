# 十个 site 的协变量臂和概念臂

每个 site 用自己的 burn-in（batch 0–7）对自己的改写窗（batch 8–15）。MMD 和 HSIC 只看 X，是协变量分数。R-risk 是 burn-in 上拟合的模型在改写窗上的超额均方误差，是概念分数。森林那一列把同一个缺口换了模型类。五次重复。标签规则是十站方案：S0–S3 干净，S4–S6 三个半空间，S7 是乘积，S8 是 sin 方，S9 是掷硬币。协变量是相关的合成表，基线标签用的是 v3、v4、v5，不是被改写的那几列。

## 这三列不是同一个名次

协变量臂不提供排序。结构化站点和干净站点比，MMD 上“主驱动更大”的配对比例是 0.49，HSIC 是 0.55。MMD 名次和 ridge R-risk 名次的 Kendall τ 是 −0.03。用 MMD 取前五名，命中真正改写规则的比例是 0.52，和随机抽五个一样。设计里 P(X) 在站点和时间上都是同一份，这个零结果是对的。它也说明：一旦有人用协变量分数给 site 排座次，排出来的是抽样噪声的一个排列。

概念臂看得到改写，但看得到不等于能点名。Ridge 上，主驱动大于干净站点的配对比例是 0.85，噪声大于干净站点是 1.00，主驱动大于噪声只有 0.56。噪声站点的平均名次是 3.8（1 是最高），五次里有一次排到第 2。它落在线性站点的带里：S4 的 ridge 是 0.020，S9 是 0.046，S6 是 0.049。乘积站点 S7 的 ridge 只有 0.014，和干净的 S0（0.012）叠在一起。Ridge 取前五名，命中五个结构化站点的比例是 0.72。硬币站会挤进来，乘积站会掉出去。

换模型类，名次就换。森林把 S7 从 0.014 抬到 0.113，高于全部三个半空间；S8 在五次重复里都是第一。线性站点大于非线性站点的配对比例，ridge 是 0.37，森林是 0.03。两列 R-risk 的 Spearman 相关是 0.67，Kendall τ 是 0.54。森林把噪声的平均名次压到 5.8，前五名命中率 0.96。这不是森林“找到了那个驱动”，是森林能拟合乘积和 sin 方，所以超额误差跟着可拟合的翻转量走。S8 改写一半的行，S4 只改写上尾里的大约四分之一。幅度大的站点不是更“主”的机制，是被改写的行更多，而且模型类刚好能写下那个规则。

两轴一起看也定不出一个集合。(MMD, ridge R-risk) 的 Pareto 前沿五次分别是：一个线性站；干净、线性、非线性、噪声全在上面；两个非线性站；干净加两个线性加一个非线性；线性、非线性、噪声。MMD 的差别是噪声，谁的 MMD 稍微大一点谁就支配不了别人。前沿因此会放进干净站和硬币站。保留两轴不会把归因变唯一，只会把集合变大、变不稳定。

特征层同样不能点名。概念漂移站点上，ridge 的留一坐标重要度对种植坐标的 AUC 是 0.72，MMD 的是 0.52。五条结构化规则都用 v0。v0 亮了，同时兼容半空间、乘积和 sin 方。基线标签在 v3、v4、v5 上，burn-in 模型用过它们，改写之后这些预测会变旧，置换也会在从未漂移的坐标上掉误差。一条 LOCO 曲线分不开“旧概念用过”和“新概念用上”。

## 为什么唯一归因是不可能的

能估的是联合分布变化的两个投影，不是机制本身。

协变量投影是 X 上的核距离。这个设计把每个站点、每个时间窗的 P(X) 设成同一份，所以估计量在站点之间可交换，任何全序都是噪声的全序。

概念投影是某个函数类的超额风险。超额风险不是概念漂移。它是这个函数类能写下的那一部分漂移，减去本地拟合在同一类里补回来的部分，再加上标签噪声对两个拟合的影响。三个半空间、一个乘积、一个 sin 方、一次掷硬币，映到这个标量上是重叠的：S9 和 S5、S6 在 ridge 上分不开，S7 和 S0 在 ridge 上分不开，S7 和三个线性站在森林上又分开了。从一个名次反推回“是哪一个站点、哪一种机制”，原像不是单点。

名次是全序。全序要求先选定一个泛函：只看 MMD，只看 ridge，只看森林，或者把两轴压成 Pareto。上面四次选择给出四个不同的顺序。不存在一个与这个选择无关的“那个 ranking”可以去 justify。能做的是筛查：干净站点的缺口在零附近或为负；森林缺口把结构化改写和干净站点分开。不能做的是把某一列晋升成唯一的驱动排序。

这和之前 Δ_cf 要乘技能门是同一件事。噪声站点的联合分布确实变了，本地模型又学不到稳定的概念，原始超额风险会把它排进主驱动。技能门是一个额外的约定，用来把“标签不再能被 X 解释”从“概念换成了另一个可拟合的规则”里拿出去。约定可以写清楚。它不是从 (MMD, HSIC, R-risk) 里辨识出来的。
