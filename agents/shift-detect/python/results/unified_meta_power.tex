\section{Pipeline (portable)}
\text{spaCy}+\text{VADER} produce meta $M$; BiasFinder BERT gives embedding $Z$.
\[
X=[Z_{\mathrm{PCA}},\,M],\qquad
\text{list-indices maintained in \texttt{feature\_schema.py}}.
\]
Detection: RFPerm / DRPerm. Localization: CFPerm LOCO on named blocks.
Text packages are encapsulated (\texttt{en\_core\_web\_sm}, \texttt{vaderSentiment}).
Video meta packages (optional / out of scope): OpenCV, PySceneDetect, librosa, Whisper, Ultralytics---same block+index pattern.

\section{Conclusions}
\begin{enumerate}[leftmargin=*]
  \item \textbf{Power}: meta helps on structure-aligned covariates (syntax $+0.90$, sentiment $+0.60$; RQ $+0.47$).
  \item \textbf{Localization}: $X=[Z,M]$ + block indices make CFPerm a named-block test (heldout $+0.23$, syntax $+0.09$).
  \item \textbf{Cross-modality}: list-indices separate embed vs meta modalities after digestion/interaction.
  \item \textbf{Portability}: spaCy/VADER are packaged; video meta is the same schema with different packages (optional).
\end{enumerate}
